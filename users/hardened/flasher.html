Keychron Q3 firmware flasher

Flashes a .bin file to the STM32 DFU bootloader over WebUSB. This page makes no network requests; your firmware never leaves your computer.

1Put the keyboard in DFU mode and connect

Unplug the keyboard, hold Esc, plug the cable back in, then release. (Fallback: remove the spacebar keycap and hold the reset button on the PCB while plugging in.) The keys and lights stay dead while it is in DFU mode.

Not connected

Flash protection is on

This chip refuses to erase or write its flash while read-out protection is on. Removing it is a standard STM32 step: the chip wipes its whole flash and turns protection off. The current firmware is lost and can't be backed up (protection blocks reading it). The built-in bootloader is not affected.

Afterwards the keyboard restarts with empty flash, so Esc can no longer put it in DFU mode. Unplug it, then hold the reset button under the spacebar while plugging it back in, and connect again here.

2Back up the current firmware (recommended)

Reads the whole flash and saves it as a file, so you can go back to exactly what is on the keyboard now. This fails if the vendor enabled read-out protection.

No file chosen

4Flash

Erases only the pages the new firmware needs, writes it, reads it back to verify, then restarts the keyboard.
